One line, 78 characters — the funniest error message a kitchen toaster would show its owner:

> ERROR E07: You pushed the lever without asking. I am filing this under 'rude'.

`main.py` keeps the line as data and writes it to `/output/entry.txt` only after the 1–120 character, single-line gate checks out at run time.
